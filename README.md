
# Utkarsh Trivedi - The Digital Maverick Portfolio

This repository contains the complete source code for my personal portfolio website, an interactive digital experience built from the ground up. This isn't just a resume; it's a fully interactive playground designed to showcase my skills in a memorable and engaging way.

**Live Site:** [https://utkarshtrvd-dev.github.io/](https://utkarshtrvd-dev.github.io/)

---

### Core Concept

The "Digital Maverick" theme is woven into every element, blending a high-energy, neon aesthetic with playful interactivity to reflect a passion for both creative design and robust engineering.

### Key Features

-   **🎮 Playable Background:** The entire site features a live, playable "Maverick Breaker" game as its background, complete with sound effects.
-   **🃏 TCG Project Deck:** My projects are presented as a dynamic, swipeable deck of collectible trading cards, each with unique, AI-generated art and thematic stats.
-   **🐍 Hidden Easter Eggs:** Discover a playable game of "Cyber Snake" by hovering over the interactive contact lights.
-   **💡 Focus Mode:** A user-controlled toggle pauses all games and animations, providing a clean, focused reading experience for visitors who are short on time.
-   **🕹️ Interactive Outro:** The experience concludes with a "Final Checkpoint" footer, displaying live session stats like time on site and projects viewed.
-   **✨ Advanced UX/UI:** Features a custom neon orb cursor, magnetic buttons, parallax scrolling, and a fully responsive design for a flawless experience on any device.

### Tech Stack

-   This project is built entirely with **vanilla HTML, CSS, and JavaScript**, demonstrating core web development proficiency without reliance on external libraries or frameworks.
